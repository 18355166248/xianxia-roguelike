# 《仙途劫》破境构筑系统重构

日期：2026-08-02

## 目标

把当前“随机拿一张数值卡”的升级流程，重构为玩家能主动追求、逐步成形、最终产生战斗质变的仙侠构筑系统。

升级体验必须同时回答四个问题：

1. 这一选会立刻改变什么？
2. 它属于哪条修行路线？
3. 再拿什么可以形成联动？
4. 这套构筑最终会变成什么？

## 当前证据与问题

当前实机证据：`docs/design/audit-2026-08-02/upgrade-rework/01-current-upgrade-choice.png`。

### 规则问题

- 当前只有 8 个升级，每个 3 阶；除了主动技能解锁，多数升级只是伤害、攻速、生命和回复的线性增长。
- `showUpgrade()` 实际只请求 2 个候选，但 `pickUpgradeChoices()` 固定按“锋芒 → 玄术 → 守元”取牌。因此候选数为 2 时，守元常被结构性排除。
- 三条路线只有计数和颜色差异，没有路线阈值、专属机制、前置条件或跨路线联动。
- 同一功法的第二、三阶大多只是数值增加，缺少弹道、触发方式、目标选择、范围或代价的行为变化。
- 没有重掷、炼化、锁定或保底，随机结果无法被玩家管理。
- 首领和精英奖励没有承担“构筑质变点”的职责，普通升级与关键升级的仪式强度接近。

### 展示问题

- 两张卡虽然能说明本阶收益，但没有展示“距离流派成形还差什么”。
- 路线标签只表达分类，不能承诺玩法结果。
- 进度点只代表单卡等级，无法呈现共鸣阈值、组合前置或即将解锁的终极功法。
- 选择完成后只有短时确认与常驻数值，缺少一次能直接看见的新能力演示。

## 市面机制提炼

### Hades：前置条件与双系联动

双神祝福把两个既有选择转化为新的组合能力；传奇和双神祝福拥有出现条件，玩家会为了未来高价值选项主动规划当前构筑。可借鉴“已满足 / 尚缺一项”的显式前置提示，不照搬神祇包装。

来源：

- https://www.supergiantgames.com/blog/brace-for-the-big-bad-update/
- https://www.supergiantgames.com/blog/hades-the-nighty-night-update-patch-notes/

### Vampire Survivors：进化承诺

基础武器与其他条件共同导向进化版本，进化是局内清晰的阶段高潮。可借鉴“功法圆满 + 对应法印 = 真诀”的成形结构。

来源：https://poncle.games/operation-guns

### 20 Minutes Till Dawn：升级树与首领质变

大量升级沿不同进化路线展开，首领秘典提供显著强化。可借鉴“小境界选择支路，精英/首领提供带代价的质变功法”。

来源：https://store.steampowered.com/app/1966900/20_Minutes_Till_Dawn/

### Death Must Die：系别身份与协同

祝福由不同神系聚类，玩家围绕少数系别建立协同构筑。可借鉴每局限制主修数量，让路线身份更加清晰。

来源：https://store.steampowered.com/app/2334730/Death_Must_Die/

### Brotato：标签、取舍与短循环

武器和道具数量丰富，但通过角色特性、武器槽和波次商店形成明确约束。可借鉴有限功法槽与“拿到新功法就必须放弃或炼化”的取舍，不引入局外付费装备层。

来源：https://store.steampowered.com/app/1942280/Brotato/

## 新系统：道种 → 法印 → 共鸣 → 真诀

### 1. 道种：每局先确定一个核心承诺

首次破境不再发普通数值牌，而是三选一道种：

- 剑潮道种：飞剑数量、穿透、回旋和剑潮爆发。
- 雷篆道种：技能触发雷印、连锁和蓄雷引爆。
- 青木道种：受击化盾、回复转伤害和持续作战。

道种不是锁死路线，而是提高对应牌权重，并决定主修共鸣的最终真诀。

### 2. 功法与法印：行为改变优先于百分比

升级池分为三类：

- 功法：决定攻击主体或主动技能，例如御剑、剑阵、天劫。
- 法印：改变功法行为，例如穿透、回旋、分裂、引雷、吸血。
- 命格：提供基础生存或节奏属性，只作为补足牌，不承担主要乐趣。

同一功法三阶改为：

- 一阶“开式”：解锁玩法。
- 二阶“化式”：改变行为。
- 三阶“圆满”：与法印产生强联动，不只加数值。

示例：

- 御剑诀一阶：自动御剑。
- 御剑诀二阶：飞剑命中后回旋一次。
- 御剑诀三阶：回旋飞剑会追击带有剑痕的敌人。

### 3. 路线共鸣：拿同系牌要有阶段奖励

按当前三章修为总量计算，关底前通常只能触发约 3–4 次普通破境：第一章前三波约 349 修为，第二章约 516，第三章约 530；当前阈值累计需要 50、75、112、168……修为。因此原提议的 3 / 6 / 9 重无法在单局内兑现，必须按真实局长调整。

三条道基保留，但改为短局可兑现的阈值。道种初始提供对应路线 2 重，普通同系牌提供 1 重：

- 3 重：小共鸣，拿到第一张同系牌后立即解锁路线被动。
- 5 重：大共鸣，在三次同系深化后明显改变战斗循环。
- 关底前：根据 5 重主修或 3 + 2 双修，必定提供一次真诀/天机质变。

建议效果：

- 锋芒 3：飞剑首次命中刻下剑痕；5：剑痕被功法引爆后生成追击飞剑。
- 玄术 3：释放功法积累劫力；5：满劫力自动追加天雷并复制最近一次功法的部分效果。
- 守元 3：溢出回复转化为护盾；5：护盾破裂释放剑气，低血时获得一次短暂无敌。

### 4. 双路线天机：让混搭也有目标

当主路线达到 3 重、次路线达到 2 重时，关底前的悟道奖励必定出现一张对应天机：

- 锋芒 3 + 玄术 2：雷引万剑——飞剑命中雷印目标时触发连锁雷光。
- 锋芒 3 + 守元 2：血剑归元——飞剑击杀返还护盾，护盾破裂产生追击剑。
- 玄术 3 + 守元 2：周天生息——释放主动功法时回复，并把溢出回复转为劫力。

天机只占独立槽，不挤掉已有功法等级。

### 5. 真诀：每局至少一次构筑高潮

进入关底波次前不再发普通升级，而是检测当前构筑并提供两张真诀/天机。这样质变能力能在首领战中真正被使用和验证，而不是击败首领后才拿到：

- 必须满足清楚的前置条件。
- 选项展示“已满足”的功法和法印。
- 真诀改变角色战斗表现与特效，不只提升百分比。
- 真诀可带一个明确代价，形成取舍。

示例：万剑归宗——御剑诀圆满 + 锋芒 6；飞剑周期性汇聚后齐射，但普通御剑间隔暂时增加。

## 新发牌规则

每次普通破境展示 3 张，而不是 2 张：

1. 一张“深化”：优先当前主修或已拥有功法的后续节点。
2. 一张“联动”：优先能推进共鸣、天机或真诀前置的牌。
3. 一张“破局”：从防御、机动或次修路线中提供当前构筑缺失能力。

规则约束：

- 首次破境固定三道种，不混入普通牌。
- 连续两次没有主修牌，第三次至少出现一张主修牌。
- 满足天机或真诀条件后，下一次对应奖励位必出，不依赖纯随机。
- 同一屏不出现两个只改变基础数值的命格。
- 每局提供 1 次“观星”重掷；拒绝全部选项可“炼化”，回复少量气血并积累下一次稀有牌概率。
- 已满阶项目从池中移除，但它的联动牌权重提高。

## 升级卡信息结构

每张卡固定六层：

1. 路线与类型：锋芒 · 法印。
2. 名称与阶位：回风剑印 · 化式。
3. 立即变化：飞剑命中后回旋一次。
4. 实战差异：单体追击增强 / 对群不变。
5. 构筑推进：锋芒 2 → 3，将激活“剑痕”。
6. 前置预告：万剑归宗还需“御剑诀圆满”。

如果本次选择会立即激活共鸣、天机或真诀，卡片顶部使用唯一的高亮标记“此选成诀”。

## 选择后的强化体验

升级确认分三拍，总时长控制在约 1.2 秒：

1. 0–240ms：所选卡收束为真实法宝图标，飞向角色。
2. 240–720ms：角色脚下出现路线共鸣，显示名称、阶位和本次行为变化。
3. 720–1200ms：在角色附近自动演示一次新能力；演示伤害不参与真实结算，或只对当前敌人造成受控伤害。

普通升级使用短反馈；共鸣、天机和真诀分别提升音画强度，避免每次升级都像终极奖励。

## HUD 与构筑查看

- 战斗常驻只展示主修名称、三路线重数和一个“下一成形目标”。
- 点击道基面板展开“修行卷”：当前功法、法印、已激活共鸣、真诀前置和实时属性。
- 新获得或发生变化的项目使用 3 秒高亮，不持续闪烁。
- HUD 不展示完整公式；详细数值放在修行卷，战斗中优先表达行为和成形进度。

## 首轮落地范围

为了验证玩法，不一次性制作数百张牌。首轮建议：

- 3 个道种。
- 3 条路线各 4 张专属牌，共 12 张。
- 3 张双路线天机。
- 3 张真诀。
- 3 张通用命格。
- 总计 24 张可选内容。

先覆盖御剑、剑阵、天劫、护体四个现有系统，复用现有法宝图标与战斗特效，再根据实测扩展牌池。

## 单局节奏

1. 第一次破境：固定三道种，建立本局目标。
2. 中段 2–3 次破境：按照“深化 / 联动 / 破局”三槽发牌。
3. 地图奇遇：影响牌池权重或提供一次观星/炼化，不直接送纯数值。
4. 进入关底前：根据当前 5 重主修或 3 + 2 双修，发一次真诀/天机二选一。
5. 首领战：让玩家立即使用刚成形的套路完成验证。

若实测第一章只能稳定获得 2 次中段破境，应优先把 `xpNeed` 成长从 1.5 调低或在波次结算补足修为，而不是继续降低共鸣条件。目标是每章形成“道种 + 2–3 张构筑牌 + 1 张关底质变”的完整短局循环。

## 验收指标

- 玩家 2 秒内能说清“立即得到什么、推进哪个套路、还差什么成形”。
- 连续 5 次升级至少出现 2 次行为变化，不允许全部是百分比增长。
- 每局在正常升级次数内至少能完成一次 3 重共鸣，并在关底前获得一次天机或真诀。
- 三种道种的核心战斗表现可通过录像盲测区分。
- 相同道种至少存在两条有效构筑路径，避免伪选择。
- 发牌测试覆盖保底、满阶移除、天机必出、真诀前置和炼化概率。
- 手机视口下三张卡均能显示立即变化与成形推进，正文不低于可读尺寸。
