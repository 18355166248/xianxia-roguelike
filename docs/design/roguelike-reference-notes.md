## 当前原型审计

1. 地图有清晰道路轮廓，但缺少场上可争夺地标，玩家最优策略长期是绕圈走位。
2. 波次 HUD 只显示章节和序号，没有“本波是什么、还剩多少、现在该做什么”。
3. 破境三选一卡片信息完整，但标题、描述、类型、阶位共用一段文本，扫读速度偏慢。
4. 水墨背景与玉色 HUD 已形成识别度，应保留，不照搬像素风或高饱和卡通界面。

## 本轮产品决策

- 每波在道路内生成一个“灵脉阵眼”，玩家需要驻足引灵后获得十秒增益。
- 剑脉提升 25% 伤害，灵泉持续回复气血；阵眼位置随波次变化，制造走位取舍。
- 波次卡片显示敌人主题、剩余敌数；独立目标条显示本波意图与阵眼状态。
- 破境卡片拆分标题、效果、功法/心法标签和三阶进度，保持三选一但提升扫读效率。
- 进一步把候选稳定拆成“锋芒 / 玄术 / 守元”三路，借鉴同类产品每次升级都要形成明确取舍
  的原则，但不引入局外装备或商店；每条路线仍复用当前仙侠功法与法宝图标。
- 地图入口改为双章节卡片，直接说明每张地图的路线与机关差异。
- 竹林采用左右错位的可破坏竹障，不把整条路完全封死，玩家可以选择绕行或主动开路。
- 击破竹障额外获得修为与劫力，让“绕行更安全、破障收益更高”成为真正的路线选择。
- 精英波先预警再出怪，首领波进入独立竹心圆场，借鉴“波次读秒—压力跃迁”的清晰节奏，
  但保留当前章节式闯关结构。
- 章节卡展示风险标签和两项核心机制；战斗 HUD 用四段道途节点持续显示普通波、精英波与
  首领波的相对位置，波次开场同步预告剑脉或灵泉收益。
- 章节入口进一步借鉴 Archero 的短地图段落感，把三张平铺卡收敛为“章节节点 + 单章展开”
  路线卷轴；展开区固定串联地图机关、一次性奇遇和关底首领，让入场前预期与局内事件一致。
- 章节节点只负责切换预览，主按钮才确认入场；这保留了移动端低操作门槛，同时避免在比较
  地图时误触直接开战。
- 路线节点追加“已破”道印，展开区展示通关次数与最快历时，把同类动作 Roguelike 的重复挑战
  反馈收敛成轻量章节目标；它只记录胜利，不承担章节锁定，避免局外进度阻断当前三章体验。
- 继续借鉴 Hades 的“首次悬赏 + 表现记录”分层，但不复制复杂终局系统：三章首破分别给剑伤、
  移速和气血小成长，路线页提前展示，胜利战报即时确认；之后的重复通关只刷新次数与最速。
- 胜利战报进一步落实 Victory Screen Commendations / Permanent Record 的信息优先级：
  首破永久奖励使用独立奖励主卡和延迟半拍的落印动效；刷新最速显示时间；普通重复通关显示
  次数与既有最速。三章继续共用单页结算骨架，但用章节标题、收束语、色彩和真实序列帧建立
  不同章节身份，不增加新的统计页或跨产品装饰语言。
- 章节入场吸收 Hades 对地图转场与首次进入场景的呈现原则，但不复制其等距镜头或希腊字形：
  1.9 秒内先让真实底图落定，再显示章节名与路线方向，最后揭示首境目标。青石剑碑、竹林
  焚障、寒潭潮纹直接复用局内坐标和真实序列帧；计时、输入与刷怪只在演出结束后恢复。
- 延续 Hades 房间奖励预告所代表的“先看见风险与回报，再承诺路线”原则：局内奇遇在 HUD
  提前说明分岔发生的波次，选择卡同时展示立即收益与下一波敌人修正；选定路线继续保留在
  战斗 HUD 和战报中。这里不复制房间地图或多层岔路，只提升当前四波章节的决策可读性。
- 进一步把竹林两条路线从数值标签落实为空间差异：焚竹路线清空竹障并改为正面出怪，入影
  路线重建三段交错竹障并左右交替出怪。借鉴的是 Hades“出口预告下一房间”和 Dead Cells
  “分支通向不同路径”的承诺一致性，不复制其地图规模或横版结构。
- 寒潭继续沿用同一原则，但把路线承诺落到环境危险本身：逆祭路线让祭纹成为可见的聚敌潮线，
  立刻唤潮并提高寒潮对敌伤害；封脉路线让法宝标记成为可站位的避潮结界。这样两张卡不是
  “伤害/回复”的换皮数值，而是分别改变敌群位置和玩家安全区，保持选择预告与实战空间一致。
- 青石把同一原则应用到基础地图机关：悟痕路线以三碑纵阵接管原有阵眼，要求玩家把追兵引入
  增伤圈；调息路线保留驻足引灵，但把每波阵眼改为交替侧路灵泉。借鉴的仍是 Hades 出口预告
  与 Dead Cells 分支路径的“承诺可兑现”，不扩大地图规模，也不添加新菜单层级。
- 三章选择确认统一增加“道途已定”揭示层：先显示路线角色与地势名，再显示空间后果和即时
  收益，约 1.2 秒后才恢复战斗并播放波次横幅。这里借鉴的是 Hades 的出口符号识别与
  Dead Cells Passage 的节奏分隔，不复制等距房门、横版中转层或其原作美术。
- 延续 Hades 用出口图标把承诺直接落到房间入口的做法，风险路线的短特效不放在结果面板里，
  而是逐一绑定剑碑、旧竹障和寒潭祭坛的真实场地坐标。玩家先看见“哪里发生了变化”，再读
  路线结果，确认转场不再只是 UI 层的姿态反馈。
- 同类动作 Roguelike 的防守或恢复选择通常不会与高风险奖励使用同等爆发强度；因此稳健路线
  也兑现真实场地动画，但改用更低不透明度、更小缩放和更慢收束。这样六条路线都有可见反馈，
  同时仍能从动势判断“强攻 / 稳守”，而不是靠面板颜色硬分。
- 章节卷轴进一步把“入口先预告、入场后兑现”做成同一套动作语言：切换章节时只在地图缩略图
  内播放一次对应稳健纹样，玩家先形成青石水纹、竹林风环、寒潭结界的视觉记忆，入场后再在
  真实坐标看到完整版。它借鉴出口/门扉预告的低成本识别，不复制额外房间地图或循环菜单动画。
- 入口预告进一步允许玩家点开“路线奇遇”双路线简报，在承诺进入章节前横向比较高风险与
  稳健路线的法宝、空间后果、即时收益和下境修正。简报复用局内事件配置，只提供认知预演，
  不在菜单提前做选择；这延续 Hades / Dead Cells 的入口承诺原则，同时避免复制房间地图或
  增加第二套路线状态。
- 路线卡的空间承诺不再只停留在文字：点击后将战斗内真实特效和真实场地坐标压缩投影到章节
  缩略图，玩家能在入场前直接比较“三碑 / 三泉”“两处焚障 / 三段夹道”“上层祭坛 /
  下层结界”。这里借鉴的是出口预告对下一空间的可视承诺，不复制原作地图拓扑，也不把菜单
  预演误写成正式路线状态。
- 早期版本曾在第一波用约 2.8 秒“分岔预见 · A / B”重复入口记忆；独立 `stage-entry`
  已经承担这层空间交代后，第一波改为可执行的章节动作：抢剑脉、破下障或入圈候潮。真实
  标记与章节化来敌方向共同回答“现在去哪里、为什么去、压力从哪里来”，目标完成后再回到
  实时波次 HUD。旧提示仅由 `qaBranchMemory=1` 保留作回归，不进入正式流程。
- 奇遇真正触发时再用约 0.72 秒完成一次空间兑现：高风险落点先闪、稳健落点后闪，随后才
  打开双路线卡。它借鉴出口门扉“跨过门槛前再确认一次去向”的节奏，但仍保持当前单场战斗
  结构，不新增房间切换；回闪只承接认知，不提前结算任何路线效果。
- 结算继续借鉴 Hades 的 Run Summary / Permanent Record 思路，把“我走了哪条路”和“这条路
  最终带来什么”放到同一复盘链，但不增加新的结算分页或常驻地图。默认战报仍只显示一行
  奇遇印记；玩家主动展开后，才在全屏回放中看到入口空间、正式选择和最终战果三段证据。
- 路线回放复用入场预演和战斗确认的同一套章节底图、真实序列帧与坐标投影，不录制视频、
  不重演战斗状态，也不从当前属性猜测历史。这让入口承诺、局内兑现和战后验证成为闭环，
  同时保持当前 3–5 分钟竖切的单页结算节奏。
- 进一步吸收 Slay the Spire 2 移动地图“直接标出准备走的路”的原则：双路线简报和战报回放
  都从入境点起笔，依次连接真实场地落点并收束到关底。当前版本不开放自由绘制，避免在
  168 像素缩略图上增加误触；墨迹只复述当前预演或本局已选路线，不产生第三套路线状态。
- 战斗 HUD 延续其“顶部状态少字、图形更易触达和辨认”的原则：奇遇触发点以分岔菱形嵌入
  四境连线，选择后仅对分岔之后的路径着色；单行摘要舍弃事件标题与“已择”等冗词，直接显示
  空间分支、当前境数和路线代价。路线色只强化已有状态，不产生新的可点击顶部控件。
- 关底阶段反馈进一步吸收 Hades 的短换相与可靠血条原则：进入首领波后用专属 HUD 替换普通
  目标/路线条，在血条上直接标出 55% 转相点；第一相预告下一相风险，第二相显示当前已生效
  的增援与机制。1.05 秒转相卡只承担“规则已改变”的确认，不暂停战斗、不伪造额外无敌。
- Hades 官方 Nighty Night 更新把“激烈战斗更容易解析，同时不损失冲击力”列为视觉特效目标；
  其后续补丁还持续让攻击视觉贴近命中范围，并避免在狭小房间塞入不适合的试炼效果。当前
  首领招式因此不再只换颜色：青石用三枚连续地印表达移动节奏，竹林以场地宽度和真实竹障
