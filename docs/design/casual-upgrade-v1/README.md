# 休闲进化界面 V1

## 设计目标

把破境从“阅读构筑说明”改成“两秒看懂、点卡即生效”的休闲进化选择。
战场始终保留在上半屏，三张进化牌固定对应万剑、天雷、护体三种可见变化。

视觉真值：[selected-option-2.png](https://audiopaytest.cos.tx.xmcdn.com/storages/36fb-audiotest/67/7D/GAqSoUUORnIrAAuBuwACEGay.png)

## 目标视口

- 视觉稿：390 × 844 CSS px；原始生成图 853 × 1844 px。
- Cocos：750 × 1334 设计坐标，使用固定高度策略；390 × 844 设备上的可视设计宽约 617。
- 升级面板：596 × 530，底部贴边，删除确认区后露出更多战场。
- 三张牌：170 × 344，横向等分，初始态完全同权。
- 卡片即主操作：不设默认选中，不再放置二次确认按钮。

## 信息层级

1. 上半屏继续显示真实战场。
2. 面板标题只保留“选择进化”。
3. 每张牌只展示图标、两字流派名和一句结果。
4. 三张卡都使用自身流派色描边，不制造预选状态。
5. 点击卡片后直接写入局内状态，用短暂收束动画告知结果。

## 首次进化

| 选项 | 卡片结果 | 实战变化 |
| --- | --- | --- |
| 万剑 | 飞剑 ×3 | 自动御剑从一柄提升为三柄 |
| 天雷 | 连锁 4 敌 | 周期性雷击在四名敌人之间传递 |
| 护体 | 护盾反震 | 立即获得护盾，护盾破裂释放剑环 |

## 视觉规范

- 背景遮罩：墨黑青，透明度约 18%，必须仍能看清角色与敌人。
- 面板：深墨青；外框使用低饱和青铜金，不堆叠内层卡片。
- 未选牌：青玉描边、低亮度图标。
- 初始卡片：只用各自流派色描边，不表达任何预选结果。
- 字号：标题 36；卡名 28；结果 20；按钮 28（Cocos 设计坐标）。
- 动效：按下卡片缩放反馈立即响应，进化收束不超过 0.9 秒。

## 验收标准

- 不读说明也能区分三种进化。
- 升级面板不遮挡角色和主要敌群。
- 三张牌在 390px 宽设备上无裁切，触控区域不小于 84px。
- 任意卡片都能一次点击完成进化。
- 首次进化后，三条路线分别产生数量、连锁或护盾的真实战斗差异。
