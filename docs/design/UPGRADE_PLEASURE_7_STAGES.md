# 升级快感七阶段闭环

日期：2026-08-03

本方案把升级体验拆成七个连续阶段，避免只在选卡瞬间播放一次特效，随后又退回隐藏数值。

| 阶段 | 玩家感知 | 当前实现 |
| --- | --- | --- |
| 1. 即时兑现 | 选完立刻看见新能力 | 免费释放万剑、连锁天雷或护体反震，不占常规冷却 |
| 2. 破境余势 | 升级后数秒持续强势 | 锋芒加速御剑、玄术加速功法、守元持续回盾，剑气与 HUD 同步倒计时 |
| 3. 期待与稀有 | 选之前知道价值并管理随机 | 凡/灵/地/天品、突破预告、按住预览、观星重掷、炼化回气与下次升品 |
| 4. 里程碑质变 | 3/5 重不只是数字 | 初醒/共鸣/真形符纹层级、路线共鸣被动、天机与真诀专属行为 |
| 5. 连斩滚雪球 | 强构筑在敌潮里越来越顺 | 2.6 秒击杀窗口，5/10/20 连斩进入三档剑势；受伤或超时中断，最高连斩写入战报 |
| 6. 成形目标 | 随时知道还差什么 | 最近升级条收束为法宝形态与下一共鸣/真形目标，点击仍可展开修行卷 |
| 7. 局后追求 | 一局成长连接长期记录 | 道藏保存最高连斩、最近构筑和三路线真形发现，章节入口与胜利战报同步展示 |

## 视觉资产策略

- 法宝、路线剑气和战斗特效继续复用项目已验收的真实资源。
- 突破层级使用程序化同心符纹与放射刻线，按初醒、共鸣、真形增加环数与展开幅度。
- 稀有度使用路线色、边框粗细和星级共同表达，不只依赖颜色。
- 素材加载失败时保留符纹、文字与规则反馈，不能阻断升级状态恢复。

## 验收门槛

- 手机视口能看见三张卡的稀有度、立即收益和突破预告。
- 观星消耗次数且保持升级暂停状态；炼化退出选择、回复气血并强化下一次余势。
- 5/10/20 连斩分别触发新档位，受伤与超时均会中断，历史峰值不丢失。
- 主修目标在升级强提示结束后持续可见，混修不借用主修阶段。
- 胜利后重新进入章节页，道藏记录仍可从本地存储恢复。
