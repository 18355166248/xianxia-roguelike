# 地图与玩法界面改版验收

游戏固定使用 750 × 1334 移动端画布；截图来自对应阶段的本地生产构建，新增竹林截图使用同一浏览器视口。

## 改版前

- `01-current-menu.png`：主菜单已有水墨修仙基调，但尚未传达局内地图目标。
- `02-current-battle.png`：战斗空间主要承担刷怪与走位，顶部只显示波次，缺少可争夺目标。
- `03-current-midbattle.png`：中段反馈以敌人、伤害数字和技能冷却为主，路线决策较弱。

## 改版后

- `04-improved-battle.png`：加入波次名称、阶段目标、剩余敌人数和场内灵脉地标，玩家需要在清怪与驻足引灵之间取舍。
- `05-improved-upgrade.png`：升级卡拆分为类别、标题、说明、境界与品阶，使用现有法宝图标建立稳定的信息层级。
- `06-map-select.png`：首页加入双章节地图卡，直接展示章节、地图名、玩法标签与进入动作。
- `07-bamboo-battle.png`：竹林地图使用独立背景，道路内出现两处真实竹障，HUD 同步显示剩余竹障与灵脉进度。
- `08-bamboo-upgrade.png`：竹林战斗中的破境覆盖层保持地图上下文，法宝图标与品阶信息仍可快速扫读。

## 回归结论

- 玩家状态机已由真实 4 × 4 青岚序列帧驱动，移动、普攻、技能、受击和冲刺均由运行时选择对应动作帧。
- 灵脉占领规则独立于场景表现，剑脉提供限时剑伤加成，灵泉提供限时持续回复；换波和重开都会重置状态。
- 生产构建完成，运行日志无 warning/error；规则测试与 TypeScript 严格检查通过。
- 竹障已在实际运行中承受飞剑伤害并被破坏，HUD 从“竹障 2”同步更新为“竹障 1”。
- 画布游戏目前无法从 DOM 语义层验证读屏与键盘焦点，后续若进入无障碍专项，需要为主要操作补充可访问的 HTML 壳层。

## 后续范围

下一轮可以增加竹林专属精英外观与首领动作序列帧，继续减少不同波次共用静态敌人素材带来的重复感。
