# 仙途劫：闯关 Roguelike MVP

## 一局流程

主菜单 → 进入章节 → 清理四波敌人 → 击败关底首领 → 结算 → 下一关。

战斗中玩家只控制走位，飞剑自动索敌。击杀获得修为，境界提升时从三个随机强化中选择一个，
随后继续战斗。这样既保留移动端低操作门槛，也能让构筑选择成为核心乐趣。

## MVP 边界

- 一个角色：青岚剑修
- 一个章节：青石山道
- 四波战斗：山精、狐妖、僵尸、山魈首领
- 六个强化：飞剑数量、剑伤、攻速、移速、护体、回春
- 单局目标时长：3–5 分钟

## 后续拆分

当原型验证手感后，再把 `GameBootstrap` 拆成独立系统：

- `StageDirector`：波次、关卡和胜负
- `CombatSystem`：索敌、弹道和伤害
- `ProgressionSystem`：修为、境界和强化
- `SaveService`：章节进度与局外成长
- `PlatformService`：微信登录、震动、广告和排行榜适配

暂不接局外养成、装备背包、复杂剧情和联网，避免玩法未验证前扩大工程量。
