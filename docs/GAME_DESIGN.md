# 仙途劫：闯关 Roguelike MVP

## 一局流程

主菜单 → 进入章节 → 清理四波敌人 → 击败关底首领 → 结算 → 下一关。

战斗中飞剑自动索敌，玩家以走位和三项主动功法控制战斗节奏。击杀获得修为，境界提升时从
三个强化中选择一个；未解锁的主动功法会优先进入候选，避免纯数值成长长期挤掉新动作。
这样保留移动端低操作门槛，同时让操作能力和构筑选择一起成长。

界面采用全屏战场：顶部悬浮显示角色气血、境界修为与波次，底部左侧为摇杆、右侧为自动御剑
与弧形技能簇，底部中央为天劫蓄力条。破境选择和结算使用覆盖战场的模态层，暂停战斗并阻止
HUD 穿透。

## 渐进式操作

三套操作探索不随机替换整套布局，而是收敛为同一套固定按钮的三阶成长，避免玩家在战斗中
重新建立肌肉记忆：

- 一阶轻操作：御剑自动索敌，点击主攻击键补一次快速剑击。
- 二阶方向操作：拖动主攻击键选择方向，向该方向齐射飞剑。
- 三阶动作操作：长按主攻击键蓄力，松开后释放大范围蓄力斩。

左摇杆仍负责移动；快速滑动摇杆在踏云解锁后触发闪身。踏云、剑阵和天劫保持固定位置，
不会因局内随机升级改变布局。三个独立探索稿保存在 `docs/design/control-concepts/`，当前实现
采用方案 A 的单手布局，并逐阶吸收方案 B 的定向攻击和方案 C 的长按剑招。

## 功法成长

- 御剑诀：一阶自动索敌与点击快斩；二阶增加拖动定向齐射；三阶解锁长按蓄力斩。
- 踏云步：解锁后提供短距离闪身和无敌帧；二阶提升距离与无敌时间；三阶沿途造成斩击。
- 周天剑阵：一阶五剑环斩；二阶七剑并扩大范围；三阶九剑圆满并进一步提升伤害。
- 天劫剑意：战斗命中与击杀积累劫力，满后长按释放；品阶决定一至三重落剑。

移动端通过右侧按钮释放主动功法；桌面端对应空格、Q、长按 E。冷却采用顺时针灵光环，
三个品阶光点直接显示当前成长层数。

青石山道使用随纵向位置插值的道路轮廓作为可行走区域。玩家主动移动、受击击退、敌人追击与
敌人出生点都使用同一套边界约束，竹林、岩石和道路外区域不参与战斗。更换场景图时需要同步
更新 `assets/scripts/config/ArenaConfig.ts` 中的道路轮廓，确保视觉道路与碰撞范围一致。

## MVP 边界

- 一个角色：青岚剑修
- 一个章节：青石山道
- 四波战斗：山精、狐妖、僵尸、山魈首领
- 行为差异：山精直追、狐妖迂回、僵尸周期扑进、山魈范围震地
- 四条三阶功法成长：御剑、踏云、剑阵、天劫
- 四条三阶属性成长：剑伤、攻速、护体、回春
- 单局目标时长：3–5 分钟

## 运行时拆分

功法数值与冷却已拆入 `SkillRuntime`，技能 HUD 已拆入 `SkillHudRenderer`，场景尺寸与道路轮廓
已拆入 `ArenaConfig`。本轮新增 `PlayerActionRuntime`，统一处理点击、拖动、长按和摇杆快速
滑动的阈值，并以动作优先级避免受击、冲刺、施法和普攻姿态互相覆盖。

## 后续拆分

当原型验证手感后，再把 `GameBootstrap` 拆成独立系统：

- `StageDirector`：波次、关卡和胜负
- `CombatSystem`：索敌、弹道和伤害
- `ProgressionSystem`：修为、境界和强化
- `SaveService`：章节进度与局外成长
- `PlatformService`：微信登录、震动、广告和排行榜适配

暂不接局外养成、装备背包、复杂剧情和联网，避免玩法未验证前扩大工程量。
