# 寒渊山魈 2×2 冰裂地面特效

生成路径：`assets/resources/art/effects/hanyuan-frost-impact.png`

## 提示词摘要

以寒渊山魈的青色符文、黑铁与冰晶材质，以及寒潭遗迹的月光冰面为双参考，生成严格 2×2、
完全俯视的圆形地面特效：

1. 符文细环与初生裂纹；
2. 放射状主裂扩散；
3. 高亮冰缝与环形碎晶爆发；
4. 低亮余霜、散落碎晶与消退符印。

四格保持同一圆心、直径和俯视角，每格只出现完整地面特效，不包含角色、武器、场景、文字或
跨格碎片。生成时使用纯洋红色键背景，再通过本地色键工具转成透明 RGBA，并调整为
1256×1256px，使每帧精确为 628×628px。

## 生成方式

使用 Codex 内置 ImageGen，输入寒渊山魈动作表和寒潭遗迹背景作为双参考图；未使用 CLI fallback。
