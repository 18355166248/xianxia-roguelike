# 寒潭 2×2 聚潮特效

生成路径：`assets/resources/art/effects/frost-tide-commit.png`

## 提示词摘要

以寒潭遗迹背景与现有寒渊冰裂特效表为构图参考，生成严格 2×2、完全俯视的青色祭纹聚潮：

1. 细薄祭纹水环显现；
2. 青蓝潮流沿符环旋转汇入；
3. 漩涡与祭纹核心达到峰值；
4. 潮光回落，只余稀薄水环与碎晶。

四格保持同一圆心、直径与俯视角，不出现角色、文字或跨格元素。生成时使用纯洋红色键背景，
本地移除色键并调整为 1256×1256px 透明 RGBA，使每帧精确为 628×628px。

## 生成方式

使用 Codex 内置 ImageGen；以寒潭遗迹实机背景和既有 2×2 冰裂表作为视觉与切帧协议参考。
