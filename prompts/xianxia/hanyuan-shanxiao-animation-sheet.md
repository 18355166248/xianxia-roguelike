# 寒渊山魈 4×4 动作序列帧

生成路径：`assets/resources/art/bosses/hanyuan-shanxiao-actions.png`

## 提示词摘要

以现有山魈动作表为网格、镜头和体型参考，以寒潭遗迹为配色与材质参考，生成严格 4 列×4 行
的独立冰系首领动作表。角色为黑色霜毛巨猿，佩戴裂纹冰面具、晶体肩甲与青色祈绳，使用带有
寒冰符文的黑铁柱棒：

1. 寒雾待机；
2. 碎冰追击；
3. 举棒聚寒到砸地冰浪；
4. 受击、踉跄到寒狱狂化。

每格只保留一个完整角色，身份、朝向、脚底基线与尺寸一致。生成时使用纯洋红色键背景，
再通过本地色键移除工具转成透明 RGBA，并调整为 1256×1256px，使每帧精确为 314×314px。

## 验收

- 4×4 网格尺寸可整除，四角透明。
- 待机、追击、施法和狂化在运行尺寸下仍能区分。
- 冰甲、面具、重棒和寒冰特效跨帧保持一致，没有跨格主体。

## 生成方式

使用 Codex 内置 ImageGen，输入山魈动作表与寒潭遗迹背景作为双参考图；未使用 CLI fallback。
