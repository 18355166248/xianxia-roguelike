# 竹障 2×2 焚烧特效

生成路径：`assets/resources/art/effects/bamboo-burn-commit.png`

## 提示词摘要

以竹林伏击背景与现有寒渊冰裂特效表为构图参考，生成严格 2×2、完全俯视的竹障焚尽动画：

1. 障位边缘出现暗红余烬与散落竹叶；
2. 琥珀火弧环绕、竹片开始崩裂；
3. 火弧、竹屑与灰烬集中爆发；
4. 只留下低亮炭痕与消散余烬。

四格保持同一圆心、直径与俯视角，不出现角色、文字或跨格元素。生成时使用纯洋红色键背景，
本地移除色键并调整为 1256×1256px 透明 RGBA，使每帧精确为 628×628px。

## 生成方式

使用 Codex 内置 ImageGen；以竹林伏击实机背景和既有 2×2 冰裂表作为视觉与切帧协议参考。
